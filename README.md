# پیش‌بینی عیار با بازه

مدل، عیار را از عمق، نرخ، مقدار معرف و نوع سنگ پیش‌بینی می‌کند. علاوه بر عدد نقطه‌ای، یک بازهٔ ۹۰ درصد با روش split conformal ساخته می‌شود. شعاع بازه از قدرمطلق خطای یک مجموعهٔ کالیبراسیون می‌آید که در آموزش مدل استفاده نشده است.

```powershell
cd project\interval-forecast
python main.py
```

`models/metrics.json` پوشش واقعی روی دادهٔ آزمون و عرض میانگین بازه را دارد. در اجرای فعلی MAE حدود ۰.۱۵ است، پوشش تجربی ۹۱.۶ درصد در برابر هدف ۹۰ درصد، و عرض میانگین بازه حدود ۰.۶۴ است. داده مصنوعی است.
